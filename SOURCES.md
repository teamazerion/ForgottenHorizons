# Forgotten Horizons — Sources and Credits

Forgotten Horizons is an independent educational storytelling project
created by Yohan Joseph for the NASA Space Apps Challenge.

Mission descriptions, timelines, science summaries and legacy notes
are written for this project. They are not official NASA publications.

## Image Credits and Usage

The website requests mission images through NASA's public
Images API when available.

Image availability, credit lines and usage conditions can vary.
Consult the individual image record and its rights information
before reusing any image. Do not assume every image is unrestricted.

The project banner is a separately created project graphic.
