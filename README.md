# 🌌 Forgotten Horizons

### Abandoned but Not Forgotten — Exploring the Stories Left Behind

**Forgotten Horizons** is an interactive space exploration and storytelling website created for the NASA Space Apps Challenge.

It explores the legacy of human and robotic missions by telling the stories of equipment and hardware left behind on the Moon and Mars.

🌐 **Live Website:** https://teamazerion.github.io/ForgottenHorizons/

---

## 🚀 Project Overview

Space exploration does not end when a mission finishes. Hardware left on other worlds can tell us stories about scientific discovery, engineering, exploration, and humanity's journey beyond Earth.

Forgotten Horizons turns these stories into an interactive digital experience designed to make space history engaging and accessible.

## ✨ Key Features

- 🌍 **Interactive 3D Explorer** — Explore a visual space environment with interactive mission markers.
- 🛰️ **Holographic Mission HUD** — Experience a futuristic interface with mission status and visual scanning effects.
- 🎛️ **Mission Control Dashboard** — Explore mission information through an interactive dashboard.
- 🔗 **Mission Connection Network** — Discover relationships between missions using interactive nodes and Moon/Mars filters.
- 📚 **Mission Archive** — Explore eight mission stories and their historical significance.
- 🌕 **Moon and Mars Exploration** — Discover the legacy of space exploration across two worlds.
- 📱 **Web-Based Experience** — Access the project through a browser on mobile or desktop.

## 🎯 Challenge Connection

This project addresses the NASA Space Apps Challenge theme:

**“Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars.”**

Its goal is to encourage people to look beyond mission endings and discover the scientific and historical stories associated with space hardware left behind.

## ▶️ How to Use

1. Open the live website using a browser.
2. Explore the homepage to learn about the project.
3. Open Mission Control to interact with the mission network.
4. Use the 3D Explorer to discover mission markers.
5. Visit the Mission Archive to explore the mission stories.

No app installation is required.
